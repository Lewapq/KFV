# Product

KFV is a web application with a React frontend and AWS cloud backend (infrastructure-as-code via AWS CDK).

Both the frontend and backend are currently in early scaffold stage — no domain-specific business logic has been implemented yet. The frontend renders a default Vite + React starter page, and the backend CDK stack is empty with no AWS resources defined.

The product name is **KFV**. As features are added, this document should be updated to reflect the product's purpose, target users, and core functionality.
